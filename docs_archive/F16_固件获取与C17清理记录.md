- 日期：2026-11-13

## 1. 结论摘要

1. **已按 ADB 精确版本拉取 F.16 官方全量固件包**，并取得 `boot.img`（64 MiB）、`vbmeta.img` 等 ROOT 相关镜像。仅传输 **14,234,656 字节（13.58 MiB）**，3.71 GiB 整包未下载。【实】
2. **来源为 OPPO 官方 OTA 服务器**（`component-ota-cn.allawntech.com/update/v6`），非第三方固件站；包名、OTA 版本、SPL、内核构建串与 ADB 实机逐项一致，含 fingerprint 尾号 `1704167642389` 的内嵌证据。【实】
3. **已清理 5 项 C.17 过时固件产物**（82 个文件 / 247,093,946 字节 ≈ 235.6 MiB），采用回收站方式，可恢复。【实】
4. **保留的 5 份 C.17 绑定分析文档已统一加版本失效声明**；工具的默认基线已切到 F.16 并按扩展名自动识别容器格式。【实】
5. F.16 与 C.17 的 boot 结构存在实质差异（ramdisk 由 0 变为 1,002,628、内核尺寸、SPL、容器格式、哈希全不同），任何沿用 C.17 偏移/符号的做法都会出错。【实】

### 3.4 包结构

**标准 ZIP**（开头 `PK\x03\x04`，非加密 ozip），63 条目，为完整全量包：

- `system.new.dat.br` 2,736,571,230 B、`vendor.new.dat.br` 612,195,461 B
- `boot.img` 压缩 13,144,902 B / 原始 67,108,864 B，CRC `4e78af42`
- `firmware-update/vbmeta.img` / `dtbo.img`、`META-INF/…`、`system.transfer.list`
- 中央目录 `cd_offset=3983619433`、`cd_size=4946`、EOCD 物理偏移 `3983624379`

因是标准 ZIP，无需 AES 解密；`tools/ozip_range_extract.py` 已扩展 `--plain-zip` 并按 `.zip` / `.ozip` 后缀自动识别。

## 8. 边界与仍开放项

- 整包 MD5 `c39c5cefb401881fee104cabccdfbad` 来自服务端响应头，**未下载 3.71 GiB 整包做本地复算**；所提取的 5 个文件均通过 ZIP CRC32 + 大小校验。
- 未执行 BL 解锁、Magisk 补丁或任何刷写；设备仍为 locked / green。
- `system.new.dat.br`（2.74 GB）与 `vendor.new.dat.br`（612 MB）未下载；若后续需要 `build.prop`、`recovery-from-boot.p` 或内核模块/驱动静态分析，需按同样的 Range 方法另行提取。
- 深度测试 APP 未安装，官方解锁通道未验证；F.16 是否在深度测试支持版本内仍未知。
- 临时 root 研究所需的 F.16 内核符号偏移尚未重算（旧 `kallsyms_out.txt` 已清理）；应按 `F16_基线_与C17结论失效说明.md` Step 2 用 F.16 内核重跑工具链。
- 设备来源仍存疑（2019 机型出现 2025 年 OEM 签名构建，带 `ro.boot.realme.*`），但 `release-keys + locked + green + verity enforcing` 表明是真实 OEM 构建；本记录以 fingerprint 精确匹配为准，不对来源作进一步推断。
